GitHub Pages là trang web tĩnh miễn phí. Khi bạn bấm Lưu ở trên, trình duyệt mới chỉ lưu trên máy của bạn. Để tất cả khách mời ở máy khác đều thấy đúng tên, ngày giờ và STK của bạn, bạn chỉ cần cập nhật file config.js lên GitHub theo 1 trong các cách dưới đây:

2. Mở GitHub Dán Đè & Bấm Commit

📋 3 Bước Đưa Lên GitHub Pages:

  1. Bấm nút xanh "Tải Toàn Bộ Code (ZIP)" ở trên rồi giải nén ra.
  2. Đăng nhập GitHub.com → Bấm New repository (chọn Public). Kéo thả các file trong thư mục vừa giải nén vào GitHub rồi bấm Commit.
  3. Vào tab Settings của repo → Chọn Pages (menu trái) → Mục Branch chọn main và bấm Save. Sau 1 phút thiệp của bạn sẽ online vĩnh viễn!
